# Game scene assets

`frontend/src/assets/game-scene/lunar-terrain.webp` is a resized WebP conversion of NASA's [Moon - Lunar Terrain](https://github.com/nasa/NASA-3D-Resources/blob/11ebb4ee043715aefbba6aeec8a61746fad67fa7/Images%20and%20Textures/Moon%20-%20Lunar%20Terrain/Moon%20-%20Lunar%20Terrain.jpg) illustration from the NASA 3D Resources repository. The [repository README](https://github.com/nasa/NASA-3D-Resources/blob/11ebb4ee043715aefbba6aeec8a61746fad67fa7/README.md) says its assets are free and without copyright and links to NASA's media usage guidelines. The image was resized from 4096 × 4096 to 2048 × 2048 and converted to WebP for delivery; CSS crops and darkens it in the scene. This rendered landscape is illustrative, not a photograph, and does not depict the selected landing site.

The astronaut is the existing Poly asset documented in [astronaut.md](astronaut.md). The spacecraft is the existing symbolic illustration in the application.
