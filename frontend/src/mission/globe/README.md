This view adapts the Three.js `OrbitControls`, south-pole orientation, marker projection and lunar coordinate convention from `frontend/src/landing-guide/LunarViewport.tsx` and `lunarTerrainEngine.ts` in commit `343d31f` (branch `feat/integrate-ai-studio-site`). That commit documents its integration from the AI Studio prototype `zaczusantos-ops/aistudiolandingguide` at `6d2e531`; authorship of that prototype is not established by this repository.

`lroc_color_2k.jpg` is copied unchanged from the same commit, where it is identified as the NASA SVS CGI Moon Kit LROC global mosaic. The global equirectangular atlas uses longitude −180° to +180° across the image, north at the top, and east-positive longitude. The coordinate convention is x = −cos(lat) cos(lon), y = sin(lat), z = cos(lat) sin(lon); the globe is rotated π around X, so the south pole is at world +Y. The sphere's UV longitude is shifted by half a turn to align the texture with those coordinates. Markers are projected from the same sphere and hidden on the back. This is a visual surface reference only; it does not model terrain height, terrain occlusion, illumination, or visibility.

The polar cap uses `ldem_south_pole_1k.png` copied unchanged from commit `343d31f`. That branch describes it as the packed LRO LOLA LDEM_80S_80M south polar stereographic DEM, spanning 608 km across at a 1,737.4 km reference radius. The adapted shader uses that branch's `sphereUnitToSouthStereoUv` projection and fades from the cap to the global mosaic near its 80°S coverage edge. A fixed oblique light is applied to local elevation gradients solely to show relief; it is not a simulation of the Sun, nor a terrain visibility calculation. The sphere geometry is not displaced.

The source DEM is documented in the original branch as MOON_ME, whereas this mission's geometry uses IAU_MOON. No frame transform or independent image registration has been applied here. The map is context for approximate selection, not precision landing terrain.

The comparison explorer keeps this same data and adds keyboard orbit, zoom controls, and compared-site outlines. The polar hillshade fades out between camera distances 1.65 and 2.5 sphere radii, leaving the continuous LROC mosaic at whole-Moon scale. This is a display transition only; it does not alter geographic coordinates or scientific data.
